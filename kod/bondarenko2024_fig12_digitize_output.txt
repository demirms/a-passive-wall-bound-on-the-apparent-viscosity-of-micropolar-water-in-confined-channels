4. Mappings to the Eringen variables of the paper (mu_E, kappa_E, gamma_E; eta_0 = mu_E + kappa_E/2, eta_r = kappa_E/2)
   E : Eringen variables directly: mu_E = mu, kappa_E = kappa, gamma_E = gamma. Bulk viscosity mu + kappa/2.
   H1: mu = eta_0 (bulk), kappa = eta_r (Cosserat couple viscosity, Neff/Nowacki form 2 kappa skew), gamma_E = gamma: mu_E = mu - kappa, kappa_E = 2 kappa. Bulk viscosity mu.
   H2: mu = eta_0 (bulk), kappa = kappa_E = 2 eta_r: mu_E = mu - kappa/2, kappa_E = kappa. Bulk viscosity mu.
   Closed forms in terms of N and l (with l^2 = gamma/(4 mu), N^2 = kappa/(mu+kappa)):
     E : eta_r/eta_0 = N^2/(2-N^2);       lambda^2 l^2 = N^2 (2-N^2) / [4 (1-N^2)]
     H1: eta_r/eta_0 = N^2/(1-N^2);       lambda^2 l^2 = N^2   (1/lambda = l/N)
     H2: eta_r/eta_0 = N^2/[2(1-N^2)];    lambda^2 l^2 = N^2/(2-N^2)
