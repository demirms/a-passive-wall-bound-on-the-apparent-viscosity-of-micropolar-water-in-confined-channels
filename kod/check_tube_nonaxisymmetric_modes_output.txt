==============================================================================
residual Phi_g - [(3a+b+g)/3 trG^2 + (g+b)|G^os|^2 + (g-b)|G^a|^2] = 0

==============================================================================
2. The three parts inside the fully developed setting (in-plane nu, d/dz = 0)
==============================================================================
   trace     nu=(x, y): Phi_g = 2*(2*alpha + beta + gamma)
   sym-trless nu=(x,-y): Phi_g = 2*(beta + gamma)
   antisym   nu=(-y, x): Phi_g = -2*(beta - gamma)
   in-plane gradient (d/dz = 0, nu_z = 0): residual Phi_g - [(2a+b+g)/2 trA^2 + (g+b)|A^os|^2 + (g-b)|A^a|^2] = 0
   -> in the fully developed section the pointwise conditions are 2a+b+g >= 0, g+b >= 0, g-b >= 0;
      2a+b+g = (2/3)(3a+b+g) + (1/3)(b+g), so the thermodynamic set (3a+b+g >= 0, g >= |b|) is sufficient;
      the trace condition actually needed is the weaker 2a+b+g >= 0 (nu_z, which carries d/dz-free axial spin, decouples).
