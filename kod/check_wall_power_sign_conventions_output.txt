Part B. BC3 wall power, limits, and the functional with the wall term
==============================================================================
B1 P = m_(n).nu with nu = -(l_s/gamma) m_(n): P = l_s*(-m_x**2 - m_y**2 - m_z**2)/gamma_p
   residual P + (l_s/gamma)|m|^2 = 0
   residual P + (gamma/l_s)|nu|^2 = 0
   P <= 0 for l_s > 0 and gamma > 0 (a negative multiple of a sum of squares).
   limit l_s -> 0 at fixed m_(n): nu -> [0, 0, 0],  P -> 0  (BC1: nu = 0, P = 0)
   limit l_s -> oo at fixed nu: m_(n) -> [0, 0, 0],  P -> 0  (BC4: m_(n) = 0, P = 0)
B2a symmetry Phi_bil(X,Y) - Phi_bil(Y,X) = 0
B2b residual div_xy(t[X].v[Y] + m[X].nu[Y]) - [Phi_bil(X,Y) + v[Y].div t[X] + nu[Y].(div m[X] + eps:t[X])] = 0
   -> for a solution X and a variation Y with u = 0 on the wall:
      d/de [2G int(w+e u) - int Phi(X+eY) - (gamma/l_s) oint |nu+e phi|^2]_(e=0)
        = -2 oint (m_(n)[X] + (gamma/l_s) nu) . phi ds,
      so the natural wall condition is m_(n) = -(gamma/l_s) nu, i.e. nu = -(l_s/gamma) m_(n) = BC3 (sign checked in B1).
   value at the solution: 2GQ - int Phi - (gamma/l_s) oint|nu|^2 with int Phi = GQ - (gamma/l_s) oint|nu|^2: J - GQ = 0
